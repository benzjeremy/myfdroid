### 📋 Manuelle Hinzufügen-Anleitung

1. Kopiere die Repository-URL:
   ```text
   https://benzjeremy.github.io/myfdroid/repo
   ```
2. Öffne **F-Droid** auf deinem Smartphone.
3. Gehe zu **Einstellungen** ⚙️ ➔ **Paketquellen / Repositories**.
4. Tippe auf das **+** Symbol und füge die URL ein.
