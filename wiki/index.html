⚙️ 2. Setup in verschiedenen Clients 2. Setup across Clients

F-Droid (Klassisch)

  1. Öffne F-Droid → Einstellungen → Paketquellen.
  2. Tippe oben rechts auf das + Symbol.
  3. Füge die URL https://benzjeremy.github.io/myfdroid/repo ein und tippe auf Hinzufügen.
  4. Ziehe auf der Startseite nach unten, um die Paketlisten zu aktualisieren.

Droid-ify & Neo Store (Modern Material You)

  1. Öffne Droid-ify oder Neo Store → Paketquellen / Repositories.
  2. Tippe auf Neues Repository hinzufügen (+).
  3. Füge die URL ein. Der Client liest Namen und Fingerprint automatisch aus.
